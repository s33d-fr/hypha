# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to
**[contact@s33d.fr](mailto:contact@s33d.fr)** with:

- the affected component (agent, server, interface, self-hosting kit) and version;
- the steps to reproduce the problem and its impact;
- your contact details if you want to be credited.

Please give us time to fix the problem before any public disclosure.

## Supported versions

Security fixes are made on the latest published version of the agent and of the server. The hosted
service at <https://hypha.s33d.fr> always runs the latest server. Self-hosted installations and
agents should be kept up to date (see
<https://hypha.s33d.fr/en/docs/fleet/> and <https://hypha.s33d.fr/en/docs/self-hosting/>).

## Security measures

The measures built into HYPHA (agent without open port, ed25519-signed updates, read-only
connectors, allow-listed repairs, hashed keys, log masking, audit log) are described at
<https://hypha.s33d.fr/en/docs/security/>.

N'ouvrez pas de ticket public pour un problème de sécurité. Écrivez à
